# Code Of Conduct

Vaultage is intended to be a serious security tool with a calm, respectful project culture.

## Expected Behavior

- Be constructive and specific.
- Assume security reports may involve stress and handle them carefully.
- Keep discussions focused on the work.
- Avoid publishing sensitive information, including secrets, tokens, vault files, or private logs.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publicly posting exploit details before maintainers have had a chance to respond.
- Sharing real credentials, vault files, or screenshots of secret values.
- Repeatedly derailing security or design discussions.

## Enforcement

This file is a draft until the public project governance is finalized. Before public launch, add maintainer contact details and an escalation process.
