# Vaultage Community Governance

Vaultage Community is the public Apache-2.0 source surface for My Vault and
local Projects.

## Contribution Boundary

Contributions are welcome for:

- local vault behavior,
- project scanning and `.env` export,
- import/export,
- local audit viewing/export,
- accessibility and UI quality,
- tests, docs, and release hardening.

Do not submit real secrets, vault files, provider credentials, private planning
notes, signing credentials, or closed commercial modules.

## Issue Handling

- Public bugs and feature requests can be filed in GitHub Issues.
- Suspected vulnerabilities should be reported to `security@vaultage.dev`.
- Do not include real secrets, vault exports, `.env` files, or screenshots of
  secret values in public issues.

## Brand Boundary

The Apache-2.0 license covers the Community source code. The Vaultage name,
logos, official builds, and release channels are governed by `TRADEMARK.md`.
