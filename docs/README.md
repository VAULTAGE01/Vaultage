# Vaultage Docs

This folder is the public product and implementation memory for the Vaultage
Community source drop.

Start with [../README.md](../README.md), then use the docs below for current
product and implementation details.

## Doc Map

| Doc | Use it for |
| --- | --- |
| [product.md](./product.md) | Product positioning, audience, modes, principles, and non-goals. |
| [features.md](./features.md) | Current feature inventory, status, and source pointers. |
| [architecture.md](./architecture.md) | Processes, trust boundaries, IPC, data model, and file map. |
| [governance.md](./governance.md) | Public contribution, maintainer, source-boundary, and issue-handling policy. |
| [release-provenance.md](./release-provenance.md) | Release artifact verification, checksums, provenance, and SBOM expectations. |
| [release-operations.md](./release-operations.md) | Tagging, candidate acceptance, signing-secret handling, incident response, and restore runbook. |
| [changelog.md](./changelog.md) | Chronological shipped-work log. |
| [ci-cd.md](./ci-cd.md) | CI, release protocol, and production deploy notes. |
| [repo-structure.md](./repo-structure.md) | Private/public source layout and open-core boundaries. |
| [project-scanning.md](./project-scanning.md) | Local project scan behavior, limits, and privacy boundaries. |

Private planning, competitive analysis, audits, premortems, launch handoff,
provider automation plans, and commercial strategy notes are intentionally not
included in the public source drop.
